# Proposal

## Why

The frontend dashboard should show what the user is working on right now: the campaigns and characters they opened last, and a "continue" highlight for the most recent one. Today the lists can only be ordered by name, so the dashboard shows the alphabetically first items instead. Tracking it in the browser (local storage or a cookie) would not follow the user across devices, and the server-rendered dashboard cannot read local storage.

## What Changes

- The core records when a user last opened a campaign's details (as its DM or a player) and their own character's details. Only successful reads by an allowed user are recorded.
- `GET /core/api/v1/campaign` and `GET /core/api/v1/character` accept `sort`: `name` (default, current order) or `recent` (most recently opened first; never opened ones after, by name, then id). Unknown values return 400.
- List items gain `last_accessed_at` (timestamp of the requester's last open, or `null`), so clients can show "opened yesterday".

Out of scope: access counts or "most opened" ranking (recency follows what the user is doing now and is simpler to keep), recording list views, and recording other users' characters read through a campaign.

## Capabilities

### New Capabilities

None.

### Modified Capabilities
- `campaign-list`: Adds recording of campaign opens, the `recent` sort and `last_accessed_at`.
- `character-list`: Adds recording of character opens, the `recent` sort and `last_accessed_at`.

## Impact

- **API**: Additive. New optional `sort` query parameter and a new field in list items; existing clients are unaffected.
- **Database**: New migration with `campaign_access` and `character_access` tables (user, item, last access), removed with the campaign or character.
- **Code**: campaign and character detail use cases (record the access), access repositories, list queries (join for the sort and the field), query parsing, list responses and mappers, Swagger annotations (regenerated by CI).
- **Frontend**: the dashboard lists recent campaigns and characters and highlights the most recent active campaign.
